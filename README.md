# IoT Temperature Monitoring & Forecasting

End-to-end IoT temperature monitoring and time-series forecasting system using Arduino IoT Cloud and Python.

## Features

* Real-time sensor monitoring using Arduino MKR WiFi 1010
* Arduino IoT Cloud dashboard integration
* Python API pipeline for sensor data collection
* Time-series preprocessing and feature engineering
* Temperature forecasting using machine learning

## Tech Stack

* Python
* Arduino IoT Cloud
* XGBoost
* Pandas
* NumPy
* Matplotlib

## Results

* RMSE: 0.2183°C
* MAE: 0.1676°C
* Successfully captured daily temperature patterns
